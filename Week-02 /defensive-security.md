# Defensive Security — Day 8

Today I started learning about **Defensive Security**.

So far, I have learned about networks, common attacks, and different cybersecurity threats. Today I learned about the other side of cybersecurity: how security professionals protect systems and detect attacks.

## 🛡️ What is Defensive Security?

Defensive security is the process of protecting computers, networks, applications, and data from cyber threats.

The main goal is to prevent attacks when possible and detect and respond to them when they happen.

## 🔎 Threat Detection

Security professionals monitor systems and networks to find unusual or suspicious activity.

For example, they may look for:

* Many failed login attempts
* Unknown processes
* Suspicious IP addresses
* Unusual network connections
* Unexpected file changes
* Strange user activity

I learned that detecting an attack early can help reduce the damage.

## 📋 Logs

A log is a record of activities that happen on a computer, server, application, or network.

Logs can contain information such as:

* Login attempts
* Errors
* System activity
* Network activity
* User actions

Security professionals use logs to investigate suspicious events.

## 🚨 Security Alerts

A security alert is a notification about activity that may be suspicious or dangerous.

For example, if an account has many failed login attempts, a security system may generate an alert.

I learned that not every alert means an attack has happened. Security analysts need to investigate the alert and decide whether it is a real threat.

## 🕵️ Security Analyst

A security analyst monitors systems and investigates suspicious activity.

Some common tasks include:

* Monitoring security alerts
* Checking logs
* Investigating suspicious activity
* Identifying threats
* Responding to incidents
* Writing reports

This role is interesting to me because it combines cybersecurity knowledge with problem-solving.

## 🏢 SOC

SOC stands for **Security Operations Center**.

A SOC is a team or environment where security professionals monitor and protect an organization's systems.

A SOC may use different security tools to collect logs, detect threats, investigate alerts, and respond to incidents.

## 🔐 SIEM

SIEM stands for **Security Information and Event Management**.

A SIEM collects and analyzes security-related logs and events from different systems.

It can help security teams:

* Collect logs
* Search security events
* Detect suspicious behavior
* Generate alerts
* Investigate incidents

I learned that SIEM is an important technology used by many security teams.

## 🚑 Incident Response

Incident response is the process of dealing with a cybersecurity incident.

A basic incident response process can include:

1. Detect the incident
2. Investigate what happened
3. Contain the problem
4. Remove the threat
5. Recover the system
6. Learn from the incident

The goal is not only to stop the current attack but also to prevent similar incidents in the future.

## 🧠 What I Learned Today

* Defensive security focuses on protecting systems and data.
* Logs provide useful information about system activity.
* Security alerts help identify possible threats.
* Security analysts investigate suspicious activity.
* SOC teams monitor and protect organizations.
* SIEM systems collect and analyze security events.
* Incident response helps organizations deal with cyber attacks.

## 🎯 My Learning

I found defensive security interesting because it is more than just finding vulnerabilities. It involves continuously monitoring systems, understanding what normal activity looks like, finding unusual behavior, and investigating possible attacks.
